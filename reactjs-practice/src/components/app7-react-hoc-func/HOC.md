🌟 What is an HOC in React?
A Higher‑Order Component (HOC) is a function that takes a component as input and returns a new enhanced component.
👉 HOC = Component → Enhanced Component
It is a design pattern, not a built‑in React feature.

💡 Why do we use HOCs?
HOCs are mainly used for:
✅ Reusing logic across components
(Example: auth checks, API fetch, theme injection)
✅ Adding extra props to wrapped components
(Example: passing user data, permissions)
✅ Code abstraction
(Removing repeated logic from multiple components)
